# Geomni Day11 — Soundscape Pulse

[Open interactive map](https://dongpo.github.io/geomni-30daymap-2026-day11-soundscape/) · [Watch/download 22-second MP4](https://dongpo.github.io/geomni-30daymap-2026-day11-soundscape/Geomni-Day11-Soundscape-Pulse-centered-audio-v2.mp4)

Interactive soundscape map with 300 source recordings, YAMNet candidate events and a cross-date time-of-day view (299 eligible timestamps).

Serve this directory over HTTP to open index.html. Audio is fetched from its original Internet Archive URL; availability and cross-origin access depend on the archive. Local analysis audio remains preserved outside this repository.

Map code: Leaflet and SVG. Geographical data: OpenStreetMap, ODbL. Recording licences and contributor credits are preserved in data/recordings.js. 271 recordings CC BY 3.0; 29 Public Domain Mark. YAMNet predictions are not human-confirmed accuracy measurements.

The 22-second video preserves the original 1366×1080 browser image without stretching, with an 88px caption strip. It includes the selected recording’s original stereo audio, aligned using measured browser playback timestamps (not a system-audio capture). Source: Wu, Tsan-Cheng, “滿州鄉港仔, Manzhou Township - on the beach”, https://archive.org/details/aporee_39957_45649 — CC BY 3.0 https://creativecommons.org/licenses/by/3.0/ . Audio is excerpted and transcoded to AAC, without gain changes or background music. Other map points are visual predictions only, not mixed audio.

See DATA-NOTES.txt and TIME-RECONCILIATION.html for provenance and limits. Facebook draft remains local for author review.
